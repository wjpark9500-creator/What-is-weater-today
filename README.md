# 환기 가이드

지금 창문을 열어도 될지, 오늘 하루(집을 비우는 시간 동안) 열어둬도 될지 알려주는 개인용 환기 판정 앱입니다.
기온/습도/강수는 기상청 초단기실황·단기예보, 미세먼지는 에어코리아 데이터를 사용합니다.

## 두 가지 모드

- **지금**: 현재 시점의 기온·습도·강수·미세먼지를 기준으로 즉시 판정 (`출근_환기_판정기준.json` 규칙 그대로)
- **오늘 하루**: 집을 비우는 시간대(기본 08:00~19:00, 자유롭게 설정 가능)의 시간별 예보를 모아 종합 판정. 미세먼지/강수 위험/폭염 조건은 즉시 탈락(빨강), 그 외엔 공기질·강수확률·기온·고습 지속시간·풍속을 점수화해서 4단계로 판정

## 파일 구성
```
index.html         메인 페이지
style.css           디자인
app.js              GPS/지역선택 + 모드 전환 + API 호출
manifest.json       PWA 매니페스트
sw.js               서비스워커 (네트워크 우선 캐싱)
favicon.ico 등       파비콘 세트
icons/              PWA 아이콘 세트
lib/shared.js        api 함수들이 공유하는 공통 로직 (격자변환, 위치조회, 미세먼지조회)
api/verdict.js       "지금" 모드 서버리스 함수
api/day-verdict.js   "오늘 하루" 모드 서버리스 함수
vercel.json          sw.js/manifest.json 캐싱 방지 설정
```

## 배포 방법

1. 이 폴더를 GitHub 저장소에 push 합니다 (폴더 구조 그대로 유지 — 특히 `api`, `lib`, `icons` 폴더 위치 주의).
2. Vercel에서 **New Project → 저장소 선택**.
   - Framework Preset: **Other**
   - Root Directory: 저장소 최상위
3. **배포 전에** Vercel 프로젝트 설정 → **Environment Variables** 에서 아래 두 개를 등록합니다.
   - `KMA_API_KEY` : 기상청 단기예보 조회서비스의 **Decoding** 인증키
   - `AIRKOREA_API_KEY` : 에어코리아 대기오염정보 서비스의 **Decoding** 인증키
4. Deploy.

## 코드 수정 후 배포 시 참고

- `app.js`, `style.css`, `index.html`은 서비스워커가 네트워크 우선 전략을 쓰기 때문에, 배포만 하면 모바일에도 자동 반영됩니다. 별도 캐시 버전 관리 필요 없습니다.
- `sw.js` 자체를 수정한 경우에는(캐싱 전략 등), 배포 후 모바일에서 PWA 앱을 완전히 종료했다가 재실행해야 새 서비스워커가 적용됩니다.

## 판정 로직 — 지금 모드
1. 미세먼지/초미세먼지 나쁨 이상 → 창문 닫기
2. 강한 비 / 빗물 유입 가능 → 창문 닫기
3. 공기질 좋음 + 강수 없음 + 기온 18~27℃ + 습도 40~60% → 활짝 열기
4. 공기질 좋음 + (기온 27~30℃ 또는 습도 60~70%) → 10~20분 환기 후 닫기
5. 공기질 좋음 + (기온 30℃ 초과 또는 습도 70% 초과) → 5~15분만 환기 후 닫기
6. 공기질 보통 → 10~20분 환기 후 닫기
7. 데이터 애매/누락 → 10~20분 환기 권장 (fallback)

## 판정 로직 — 오늘 하루 모드

**강제 탈락 조건 (즉시 빨강)**
- 미세먼지/초미세먼지 나쁨 이상
- 설정 시간대 중 비 예보 또는 강수확률 70% 이상
- 설정 시간대 중 최고기온 33℃ 초과

**점수제 (강제 탈락에 안 걸렸을 때, 100점 만점)**
- 공기질: 좋음 30점 / 보통 15점
- 강수확률(최고): 20% 미만 20점, 40% 미만 15점, 60% 미만 10점, 그 외 5점
- 최고기온: 27℃ 이하 20점, 30℃ 이하 15점, 30~33℃ 8점
- 고습(70% 이상) 지속시간: 없음 20점, 2시간 이하 12점, 5시간 이하 6점, 그 이상 0점
- 평균풍속: 3m/s 이상 10점, 1.5m/s 이상 5점, 그 미만 0점

| 점수 | 판정 |
|---|---|
| 80~100 | 🟢 하루 종일 열어둬도 좋음 |
| 60~79 | 🟡 짧게 환기 후 닫기 권장 |
| 40~59 | 🟠 출근 전 환기 후 닫기 권장 |
| 0~39 | 🔴 닫고 출근 |

## 알려진 한계

- 오늘 하루 모드의 미세먼지 값은 시간별 예보가 아니라 **현재 측정값**을 그대로 사용합니다. 에어코리아의 시간별 PM 예보 API는 지역 단위 텍스트 등급이라 정밀도가 낮아 채택하지 않았습니다.
- 미세먼지 등급 기준은 환경부 기준(PM10 나쁨 81㎍/㎥↑, PM2.5 나쁨 36㎍/㎥↑)을 사용했습니다.
- GPS 좌표 → 지역 이름 변환에는 무료 Nominatim(OpenStreetMap) 역지오코딩을 사용합니다.
- 공공데이터포털 API는 하루 호출 한도가 있지만(서비스마다 보통 1,000회/일), 개인 사용 용도로는 충분합니다.
